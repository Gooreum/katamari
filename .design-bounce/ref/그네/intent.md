# 그네 (일본 동네 공원 2인용 그네)

- 출처: https://www.flickr.com/photos/201306292@N07/54568697385 (2026-09-16 내려받음, main.jpg / 768 x 1024 px, 「神社と公園、ブランコ」, CC BY 2.0. 신사 도리이 옆 작은 동네 공원에 놓인 2인용 그네를 왼쪽 앞에서 비스듬히 찍은 사진. 흐린 날이라 그림자가 없고 빨간 철기둥·노란 이음쇠·은색 사슬이 색으로 또렷하게 갈린다)
- 잰 것 (A자 다리): 왼쪽 A자 꼭짓점의 노란 이음쇠가 (250, 252), 두 발은 먼 쪽 (57, 790)과 가까운 쪽 (390, 648). 꼭짓점 → 먼 발 세로 538 px, 두 발 사이 가로 333 px → 높이 : 벌린 폭 = 1 : 0.62. 기둥 굵기는 y=500 언저리에서 14 px
- 잰 것 (윗가로대와 걸이쇠): 윗가로대는 왼쪽 꼭짓점 (250, 252)에서 오른쪽 기둥 꼭대기 (745, 78)까지 화면상 525 px. 걸이쇠는 가로대 위에 넷, x = 310 · 400 · 500 · 640 — 한 그네가 걸이쇠 두 개를 쓰고(먼 그네 310·400, 가까운 그네 500·640), 두 그네 사이 간격(400 → 500)이 한 그네의 걸이쇠 폭보다 좁다
- 잰 것 (좌판과 사슬): 가까운 좌판은 x=471 → 640 (169 px), x=560 세로 단면에서 y=756 → 799 (43 px). 먼 좌판은 x=337 → 446 (109 px), y=664 → 706. 사슬은 걸이쇠 y≈180에서 좌판 y≈745까지 565 px → 사슬 : 좌판 길이 = 3.3 : 1. 좌판은 땅에 닿을 듯 낮게 걸려 있고 사슬은 고리 하나하나가 보일 만큼 굵다
- 살릴 것: ① A자 다리 높이 : 두 발 벌린 폭 = 1 : 0.62 이고 다리는 굵기가 높이의 0.026뿐인 가는 강관 · ② 사슬 : 좌판 길이 = 3.3 : 1 로, 사슬이 아주 길고 좌판은 거의 땅에 붙는다 · ③ 좌판은 두께 43 px의 납작한 고무 널 하나, 등받이도 안전바도 없다 · ④ 가로대·다리·좌판이 전부 같은 계열의 빨강이고 이음쇠만 노랑으로 튄다
- 버릴 것: 뒤쪽 주홍 도리이와 신사 담, 갈색 타일 맨션 건물, 파란 철제 울타리와 관목, 전선, 왼쪽 석조 벤치와 수도, 바닥 콘크리트 판과 배수구
- 본 것: 기둥과 윗가로대는 짙은 벽돌빛 빨강 RGB(123,44,36)~(102,7,7)이고, 좌판만 훨씬 밝고 분홍기 도는 빨강 RGB(248,78,86)이라 기둥 빨강과 명도가 두 단계 차이 난다. 이음쇠(가로대와 다리가 만나는 부분, 걸이쇠 몸통)는 겨자 노랑 RGB(173,132,36). 사슬은 무광 은회색 RGB(137,135,122). 다리 끝에는 회색 플라스틱 신발 RGB(79,80,75)이 씌워져 있다. 바닥은 콘크리트 RGB(195,191,181) 위에 적갈색 고무 매트 RGB(134,114,114)를 그네 밑에만 깔았다
- 못 찾은 것: 정면에서 찍은 그네 사진. 오른쪽 기둥이 화면 아래로 잘려 나가 그네 전체의 높이 : 폭 비율을 못 쟀고, 좌판이 땅에서 몇 px 떠 있는지도 못 쟀다(원근 때문에 바닥선을 좌판 위치까지 밀어 넣을 수 없었다). 오른쪽 기둥이 A자인지 외다리인지도 사진으로는 확인이 안 된다 — 왼쪽만 A자일 수도 있다
