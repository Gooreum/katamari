# RC 컨트롤러 (1980년대 완구 RC카 송신기, 상자형)

- 출처: https://rctoymemories.com/2013/12/30/nikko-night-stalker-1989/ (2026-09-10 내려받음, main.jpg / 1000 x 666 px — 닛코(ニッコー) 「Night Stalker」(1989) 에 딸려 온 상자형 송신기 「NIKKO R/C SYSTEMS 2 CHANNEL FULL FUNCTION 27MHz」. 흰 바탕에 눕혀 놓고 위에서 찍었고 몸통이 약 16° 기울어 있다. 몸통과 안테나 비율은 사진을 16.4° 돌려 세운 뒤 쟀다)
- 출처: https://rctoymemories.com/2024/03/03/nikko-audi-quattro-1982/ (2026-09-10 내려받음, side.jpg / 1200 x 900 px — 닛코 1/10 「アウディ クワトロ」(1982, 일본 내수판) 송신기 「SEMIDELACON」 정면. 「ライトボタン」「トランクボタン」 일본어 표시가 붙어 있다. 스틱 두 개가 달린 앞면 배치는 여기서 쟀다. 안테나 윗부분은 사진 밖으로 잘렸다)
- 고른 형태: 권총 손잡이형이 아니라 상자형(두 손으로 쥐는 납작한 네모 몸통 + 윗면 가운데 은색 막대 안테나 + 앞면 좌우 조작부). 같은 사이트의 닛코 「Super Fox」(1986) 는 권총형 송신기였으니, 1980년대 닛코 완구에 두 형태가 다 있었다
- 잰 것: main.jpg 몸통(세운 뒤) x=331 → 642, y=312 → 576 = 311 x 264 px. 가로 : 세로 = 1 : 0.85. side.jpg 몸통 x=213 → 1062, 윗면 y=145 → 바닥 y=830 = 849 x 685 px, 1 : 0.81 (양쪽 위 귀퉁이 돌기까지 치면 y=112 부터라 1 : 0.85)
- 잰 것: main.jpg 안테나 — 금속 막대 y=3 → 259 = 256 px(몸통 가로의 0.82), 굵기 약 5 px(가로의 0.016). 그 밑 검은 받침 y=260 → 312 = 52 px(몸통 세로의 0.20), 폭은 위 25 px → 아래 33 px 로 벌어진다. 몸통 윗변에서 안테나 끝까지 309 px = 몸통 가로의 0.99. 안테나 중심 x=484, 몸통 중심 x=486 — 가운데에 서 있다
- 잰 것: side.jpg 원형 스틱 우물 두 개 — 지름 약 280~290 px(몸통 가로의 0.34), 중심 높이는 윗면에서 세로의 0.42. 안테나 은색 막대 굵기 31 px(가로의 0.037), 중심 x=626(가로의 0.49)
- 잰 것: 아래 흰 상표판 — main.jpg x=359 → 621, y=462 → 526 = 가로의 0.84 x 세로의 0.24 (윗변이 몸통 세로의 0.57 지점). side.jpg x=276 → 991, y=644 → 806 = 가로의 0.84 x 세로의 0.24 (윗변이 세로의 0.73 지점)
- 잰 것: main.jpg 왼쪽 흰 조작판(터보 레버) x=367 → 456, y=356 → 438 = 가로의 0.29 x 세로의 0.31. 오른쪽 스틱 우물은 격자 눈대중으로 x≈520 → 620, y≈350 → 435 (가로의 0.32)
- 살릴 것: 가로가 조금 긴 납작한 검은 네모 몸통(가로 : 세로 = 1 : 0.85) · 윗변 한가운데 사다리꼴 검은 받침에서 몸통 가로만큼(0.8~1.0배) 곧게 솟은 가느다란 은색 안테나 · 앞면 위쪽 절반 좌우에 하나씩 놓인 조작부(원형 스틱 우물, 가로의 0.3 크기) · 아래쪽을 가로 0.84 폭으로 가로지르는 흰 상표판
- 버릴 것: 상표 글자(「NIKKO」「SEMIDELACON」 등), 주파수 스티커, side.jpg 의 어깨끈과 끈 고리, 사진 배경의 흰 천
- 본 것: 몸통은 무광 검정(main 그늘 (7,7,7), side 정면 (55,56,54) 짙은 회흑색). main.jpg 상표판은 누런 흰색(199,193,175)에 오른쪽 끝 「27 MHz」 칸만 빨강(177,88,76). 윗면 좌우 어깨에 가로 홈이 촘촘한 도드라진 턱이 있고, 아래쪽 끝도 가로 홈 무늬 띠다
- 본 것: side.jpg(1982)는 두 원형 우물 안에 네모 틀 + 원통형 스틱 받침 + 짧은 손잡이 꼭지가 있고, 가운데 세로 칸에 빨간 전원 램프와 ON/OFF 스위치, 안테나 뿌리에 홈이 파인 검은 원뿔 고리가 있다. main.jpg(1989)는 왼쪽이 원형 스틱 대신 레버가 드나드는 네모 홈이다
- 못 찾은 것: 스틱 손잡이가 몸통 앞면에서 얼마나 튀어나오는지(두 사진 모두 정면·위에서만 찍어 높이가 안 보인다). 몸통 두께(옆면) 사진. 안테나를 끝까지 뽑은 상태인지 — main.jpg 의 안테나는 거의 한 굵기로만 보여 몇 단 뽑았는지 확인 못 했고, side.jpg 는 안테나가 잘렸다
- 못 찾은 것: 타미야 조립 키트에 쓰던 취미용 송신기(후타바·산와 등 1980년대 2채널 스틱 송신기) 실물 사진 — 완구형 닛코 두 대만 찾았다. main.jpg 는 영어 표기라 해외판일 수 있다
