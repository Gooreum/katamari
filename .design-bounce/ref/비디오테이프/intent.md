- 잰 것: 창 두 개. 위 창(x=667 → 1363, y=294 → 883) 696 x 589 px, 아래 창(x=667 → 1350, y=2229 → 2820) 683 x 591 px. 창 하나 = 짧은 변의 0.47, 긴 변의 0.22. 창은 끝에서 긴 변의 0.036(위) / 0.026(아래)만 떨어져 거의 양 끝에 붙어 있다
- 잰 것: 두 창 사이 라벨 자리(움푹 들어간 판, x=654 → 1360, y=977 → 2129) 706 x 1152 px = 짧은 변의 0.47, 긴 변의 0.43. 창과 라벨 자리를 둘러싼 매끈한 가운데 판(x=635 → 1391)은 짧은 변의 0.51
- 잰 것: 짧은 변을 가로로 나누면 왼쪽부터 뚜껑 쪽 띠(x=213 → 350) 0.092 · 격자 무늬 띠(350 → 635) 0.19 · 가운데 판 0.51 · 격자 무늬 띠(1391 → 1705) 0.21
- 살릴 것: 긴 변 : 짧은 변 : 두께 = 1 : 0.554 : 0.134 인 납작한 검은 상자 · 양 끝에 붙은 투명 창 두 개(각각 짧은 변의 0.47 너비, 긴 변의 0.22 길이, 안에 흰 릴 허브) · 두 창 사이 긴 변의 0.43을 차지하는 라벨 자리 · 가운데 판 양옆의 잔 격자 무늬 띠
- 버릴 것: 라벨 자리의 까슬한 표면 결, 뚜껑 띠의 영어 인쇄("Insert this side into recorder"), 나사 구멍, 뒤의 호수와 하늘
- 본 것: 몸통은 검은 플라스틱인데 햇빛 아래라 픽셀값은 격자 띠 (84,85,84), 가운데 판 (111,109,103) 정도의 짙은 회색으로 찍혔다. 가운데 판은 잔 모래알 같은 무광 결이고, 양옆 띠는 가로세로 잔 격자가 촘촘히 새겨져 있다
- 본 것: 위 창으로는 반투명 흰 릴 허브의 아래 절반만 보인다. 아래 창으로는 감긴 테이프가 짙은 갈색 (114,97,86) 동심원 무늬로 보이고, 허브 옆에 빨간 리더 테이프 (193,110,104)가 조금 보인다. 창 안쪽 가운데에 세로로 눈금 점이 한 줄 찍혀 있다
- 본 것: 이 개체의 라벨 자리에는 종이 라벨이 붙어 있지 않다(빈 검은 판). 네 모서리는 작게 둥글다
- 본 것: side.jpg 옆면은 위아래 두 쪽 껍데기가 가로 이음선(y=161~164)으로 만나고, 오른쪽 끝 1/4(x=760 → 986)은 모서리가 둥근 따로 된 덩어리로 보인다
- 못 찾은 것: 1980년대 일본 상표(TDK·Maxell·Victor) 카세트를 정면에서 찍은 사진 — main.jpg는 1981년 무렵 제품이지만 스웨덴에서 팔린 SCENE 상표이고 라벨이 없다. Commons의 Victor 사진(JVC-VHS Cassette001.JPG)은 1990년대 S-VHS XG라 시대가 늦고 비스듬히 찍혀 쓰지 않았다. 라벨 붙은 모습, 카세트 등(뚜껑 쪽 긴 옆면)을 정면에서 찍은 사진, side.jpg의 제조 연대
