# 비스듬돌

- 출처: https://commons.wikimedia.org/wiki/File:Motsu-ji_Temple_Ikenaka-Tateishi.JPG (2026-09-16 내려받음, main.jpg / 1280 x 946 px 축소본, 원본 3928 x 2904, Sakaori 2015-04-30 촬영, CC BY 3.0. 이와테현 히라이즈미 모쓰지 오이즈미가이케 연못 가운데 데지마 석조에 비스듬히 박힌 池中立石을 물 건너에서 눈높이로 찍은 사진)
- 잰 것: 꼭대기 (x=800, y=272) → 물가 밑동 y=570, 보이는 높이 298 px. 가장 불룩한 y=400 에서 x=670 → 851, 폭 181 px. 높이 : 폭 = 1 : 0.61. 왼쪽 윤곽은 (745,300) → (620,550) 의 거의 곧은 선이고, 오른쪽 윤곽은 (833,300) 에서 (851,400) 까지 부풀었다가 (782,550) 으로 다시 들어간다. 좌우 한가운데를 이은 축은 y=300 에서 x=789, y=550 에서 x=701 → 250 px 올라가는 동안 88 px 오른쪽으로 밀려 수직에서 19.4° 기운다
- 살릴 것: 좌우 한가운데를 이은 축이 수직에서 19° 오른쪽으로 누운 자세(3° 인 세로돌과 갈리는 유일한 지점) · 높이 : 폭 = 1 : 0.61 로 세로돌(1 : 0.45)보다 뭉툭한 덩어리 · 위로 갈수록 좁아지지만 꼭대기가 한 점으로 모이지 않고 폭의 0.3 짜리 둥근 혹으로 끝난다 · 기운 쪽(오른쪽) 아래에 높이의 절반을 세로로 내려긋는 깊은 홈이 있어 거의 검은 그림자 띠를 만든다
- 버릴 것: 연못 물과 반영, 밑동을 두른 흰 자갈 둔덕, 건너편 잔디 언덕·삼나무·단풍나무, 오른쪽 물 위 작은 돌
- 본 것: 위쪽 볕 받은 면 (169,157,120), 가운데 (126,109,86), 왼쪽 아래 (136,104,73), 아래쪽 밝은 면 (167,137,100). 갈색기가 도는 회색 응회암이고, 흰 지의류 반점이 온 면에 좁쌀처럼 흩뿌려져 위쪽일수록 촘촘하다. 오른쪽 세로 홈은 거의 검다. 둘레 흰 자갈은 (205,188,162), 연못 물은 (97,110,84) 인 탁한 초록
- 못 찾은 것: 물에 잠긴 밑동 — 실제 전체 높이와 땅에 박힌 깊이를 알 수 없다. 옆에서 찍은 사진이 없어 앞뒤 두께도 모른다. 1970~80년대 일본 여염집 마당에 비스듬히 세운 돌 사진, 그리고 기운 각도를 치수로 적어 둔 작정 자료도 못 찾았다
