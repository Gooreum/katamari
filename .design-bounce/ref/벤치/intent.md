# 벤치 (일본 공원 벤치, 등받이 있는 널판 벤치)

- 출처: https://www.flickr.com/photos/37407903@N06/8184562552 (2026-09-16 내려받음, main.jpg / 1024 x 683 px, 「公園のベンチ」, CC BY 2.0. 잔디밭 가장자리에 홀로 놓인 등받이 벤치를 뒤쪽 비스듬히 위에서 찍은 사진. 겨울 낮 햇빛이 옆에서 들어와 널판 윗면만 하얗게 뜨고 주철 옆틀은 새까맣게 가라앉았다. 벤치 왼쪽 위로는 포장길이 지나간다)
- 잰 것 (전체): 벤치가 차지하는 칸은 x=445 → 858 (413 px), y=15 → 375 (360 px). 먼 쪽(왼쪽) 끝틀 꼭대기가 (445, 16), 가까운 쪽(오른쪽) 팔걸이 끝이 (862, 232)로, 벤치 축이 화면에서 오른쪽 아래로 내려오는 3/4 뒷모습이다
- 잰 것 (가까운 끝 단면): 앉는 판 앞 모서리 y=244 (x=770) → 앞다리 발바닥 y=322 (x=800), 앉는 높이 78 px. 등받이 꼭대기 y=103 (x=620) → 앉는 판 y=244, 141 px. 앉는 판 길이는 먼 끝 (500, 196) → 가까운 끝 (845, 235)로 347 px → 길이 : 앉는 높이 = 1 : 0.22 (실물 180 cm 벤치에 앉는 높이 40 cm인 비율과 그대로 맞는다)
- 잰 것 (널판): x=620 세로 단면에서 등받이는 어두운 널 3장(103–146, 154–178, 185–199)과 틈 2줄(147–153, 179–184). x=770 단면에서 앉는 판도 널 3장(164–176, 180–199, 205–244)과 틈 2줄(177–179, 200–204). 널 6장 전부 가로로 눕고, 세로 널은 한 장도 없다
- 살릴 것: ① 길이 : 앉는 높이 = 1 : 0.22 로 낮고 길게 · ② 가로 널 6장(등받이 3 + 앉는 판 3)에 널마다 널 두께쯤 되는 틈 · ③ 양 끝 옆틀은 널과 달리 통짜 주철 곡선판이고 팔걸이가 앞으로 소용돌이처럼 말려 끝난다 · ④ 다리는 옆틀 아래에서 앞뒤로 벌어져 발 두 개가 앉는 높이의 0.5쯤 되는 간격으로 땅을 짚는다
- 버릴 것: 잔디와 잔디에 길게 드리운 벤치 그림자, 오른쪽 위 아스팔트 포장길과 연석, 벤치를 역광으로 만든 겨울 저녁 광선
- 본 것: 햇빛 받는 널 윗면은 거의 흰빛에 가까운 회베이지 RGB(236,230,225)이고, 같은 널의 그늘진 옆면은 RGB(28,28,29)로 뚝 떨어진다 — 널은 나뭇결 무늬가 안 보일 만큼 매끈하다(목재라기보다 재생목 플라스틱재로 보인다). 주철 옆틀과 다리는 어디를 찍어도 RGB(30,31,33) 언저리의 먹색. 바닥 잔디는 볕 쪽 RGB(98,94,59), 그늘 쪽 RGB(80,76,44). 등받이는 뒤로 눕지 않고 거의 수직에 가깝게 서 있다
- 못 찾은 것: 정옆에서 찍은 벤치 사진. 그래서 등받이 높이 141 px은 원근 때문에 부풀었다 — 등받이 꼭대기가 카메라에서 더 먼 쪽이라 화면에서 더 위로 올라간 값이고, 실물 비율(앉는 높이와 거의 같음)보다 1.8배쯤 크게 나왔다. 그리고 목표로 삼은 「강관 다리 + 나무 널, 등받이 없는」 공원 벤치를 못 구했다 — 이 벤치는 주철 옆틀에 등받이가 달린 형이다. 벤치 아랫면·다리 접합부를 가까이 찍은 사진도 없다
