- 잰 것 (표기 치수): 便器 C710 길이 680 · 폭 356 · 테 높이 370 mm, 바닥에 닿는 발 379 × 230 mm. 탱크 S710B 폭 440(몸통 420) · 높이 435(몸통 400 + 뚜껑 35~40) · 깊이 218(몸통 210) mm. drawing-bowl.png 옆 단면에서 「370」 치수선이 x=685 → 1035(350 px, 1 mm = 0.946 px)이고 뒤쪽 탱크 받침 윗면이 x≈1040이라 받침 높이 약 375 mm → 탱크를 얹은 전체 높이 약 810 mm(계산). 높이 : 길이 : 탱크 폭 = 1 : 0.84 : 0.54
- 잰 것 (drawing-bowl.png 옆 단면): 앞면 바닥 끝 (x=685, y≈870) → 테 앞끝 (x≈1035, y≈940) — 테가 바닥선보다 약 70 px(74 mm) 앞으로 나와, 옆에서 보면 앞면이 아래로 갈수록 뒤로 들어간다
- 잰 것 (main.jpg 정면): 탱크 뚜껑 폭(y=18, x=266 → 406) 140 px, 탱크 몸통(y=80, x=271 → 399) 128 px = 뚜껑의 0.91, 뚜껑 두께 y=16 → 27(11 px = 뚜껑 폭의 0.08), 보이는 탱크 몸통 y=27 → 131(아래는 변좌 뚜껑에 가림), 변좌 뚜껑 y≈131 → 161, 변좌 링 y≈161 → 179, 변좌 폭(y=160, x=271 → 403) 132 px = 탱크 뚜껑의 0.94, 그릇 몸통 y=179 → 238에서 발(x≈303 → 373, 70 px = 탱크 뚜껑의 0.50, 도면 230 / 440 = 0.52)로 좁아진다. 레버는 탱크 앞면 왼쪽 위 모서리(x≈268 → 282, y≈36 → 44)
- 잰 것 (side.jpg 옆): 바닥 y≈320, 변좌 아래(테) y≈195, 변좌 위 y≈175, 탱크 뒤 모서리 위 y≈17 → 아래 y≈190. 테 높이 125 px, 탱크 높이 173 px(1968년 S520은 20L 탱크라 C710 + S710B보다 탱크가 크다). 그릇 앞끝 x≈160 → 탱크 뒤 x≈440
- 살릴 것: 높이 : 길이 = 1 : 0.84(약 810 × 680 mm)로 테 높이 370 위에 폭 440 · 높이 435 · 깊이 218 네모 탱크(뚜껑 두께 0.08, 몸통보다 조금 넓음)를 얹은 짜임 · 정면에서 탱크 폭 0.94의 둥근 그릇이 폭 0.50 발로 잘록하게 좁아지는 모양 · 옆에서 테 앞끝이 바닥선보다 74 mm 앞으로 나온 기울어진 앞면 · 탱크 앞면 왼쪽 위 모서리의 크롬 레버
