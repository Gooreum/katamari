# 물뿌리개

- 출처: https://commons.wikimedia.org/wiki/File:Gieter_met_broes_(Watering_can).jpg (2026-09-16 내려받음, main.jpg / 1280 x 1153 px, 원본 1578 x 1422 을 줄인 판. 벽돌 벽 앞 자갈 위에 세운 낡은 아연도금 양철 물뿌리개를 거의 정옆에서 찍은 사진, 꼭지(연꽃 꼭지)가 달린 긴 주둥이가 왼쪽 위로 뻗어 있다)
- 잰 것: 몸통 지름 — 테 높이에서 x=693 → 1080(387 px), 바닥 옆 모서리에서 x=682 → 1050(368 px). 아래가 0.95로 아주 조금 좁다. 몸통 높이 — 테 y=466 → 바닥 옆 모서리 y=1000, 534 px. 높이 : 지름 = 1.38 : 1. 바닥은 앞 가장자리가 y=1035 까지 내려와 약간 위에서 본 타원으로 보인다
- 잰 것: 몸통 가로 볼록 띠 y≈705(왼쪽 700, 오른쪽 715) — 테에서 몸통 높이의 0.45 아래. 띠 아래쪽은 녹이 번져 붉은 기가 돈다
- 잰 것: 주둥이 — 몸통 왼쪽 옆선의 y≈815 → 930 에서 나온다(가운데 y≈870, 테에서 몸통 높이의 0.76 아래). 관 윗모서리 (452,600) → (540,700)으로 수평 위 약 49°. 관 굵기 약 45 px(몸통 지름의 0.12). 몸통 옆선에서 꼭지 얼굴 가운데 (140,290)까지 약 790 px = 몸통 지름의 2.05 배
- 잰 것: 꼭지 — 나팔꼴 원뿔, 얼굴 테 (205,235) → (75,345) 지름 약 170 px(몸통 지름의 0.44, 관 굵기의 3.8 배), 원뿔 길이 약 155 px, 관과 이어지는 곳에 굵은 쇠고리(x=240 → 300, y=380 → 440). 얼굴은 왼쪽 위를 향한다
- 잰 것: 버팀대 — 주둥이 관(x=405)과 몸통 옆선(x=690)을 잇는 수평 납작 막대, y≈565(테에서 몸통 높이의 0.19 아래), 길이 285 px
- 잰 것: 윗손잡이 — 몸통 윗면 가운데에 선 납작한 띠쇠 고리, 꼭대기 y=252(테 위 214 px = 몸통 높이의 0.40), 옆에서 본 두 다리 폭 x=808 → 945(137 px, 몸통 지름의 0.35), 가운데 x≈876(몸통 가운데 886 과 거의 같다). 앞다리 아래에 네모 덧판(y=460 → 510)으로 테에 붙었다
- 잰 것: 뒷손잡이 — 테 오른쪽 끝 (1080,478)에서 나와 둥글게 뒤로 휘어 가장 바깥 x=1197(몸통보다 117 px, 지름의 0.30 뒤), y≈560 에서 꺾여 곧게 비스듬히 내려와 (1058,760)에 붙는다(테에서 몸통 높이의 0.55 아래). 띠 굵기 약 12 px
- 잰 것: 전체 가로(꼭지 얼굴 왼끝 x=75 → 뒷손잡이 x=1197) 1122 px, 전체 세로(꼭지 테 위 y=232 → 바닥 y=1035) 803 px. 가로 : 세로 = 1 : 0.72
- 살릴 것: 높이 : 지름 = 1.38 : 1 의 곧은 원통 몸통과 테에서 0.45 아래를 한 바퀴 두른 볼록 띠 · 몸통 아래쪽(테에서 0.76)에서 수평 위 49°로 뻗는 몸통 지름 2 배 길이의 가는 관(지름의 0.12)과 그 끝의 나팔꼴 꼭지(얼굴 지름 = 몸통 지름의 0.44) · 주둥이와 몸통을 잇는 수평 버팀대(테에서 0.19 아래) · 윗면 가운데 몸통 높이의 0.40 만큼 솟은 띠쇠 고리 손잡이와 몸통 뒤로 지름의 0.30 튀어나온 뒷손잡이
- 버릴 것: 벽돌 벽, 자갈과 낙엽, 왼쪽 아래 풀, 몸통 표면의 얼룩과 긁힘
- 본 것: 몸통은 무광 회녹색 아연도금 양철로, 빛 받은 윗부분 RGB(126,131,128), 그늘진 오른쪽 (83,88,86), 볼록 띠 아래 녹 번진 부분 (139,134,133)~(117,108,107), 바닥 쪽 어두운 부분 (101,110,117). 테 (107,114,120). 주둥이 관은 조금 더 푸르고 밝은 (126,138,151), 꼭지 원뿔 (116,121,122), 윗손잡이 (119,125,133). 윗면은 앞쪽 절반쯤이 둥글게 부푼 덮개로 덮이고 윗손잡이 뒤로 물 넣는 구멍이 검게 열려 있다. 꼭지 얼굴은 옆에서 보여 구멍은 안 보이고 얼굴 테만 얇은 타원 테로 보인다. 몸통 옆선은 배흘림 없이 거의 곧다
- 못 찾은 것: 1970~80년대 일본 トタン 如雨露 실물 사진 — 이 사진은 네덜란드어 파일명의 유럽식 양철 물뿌리개다. 꼭지 얼굴을 정면에서 찍어 구멍 배치가 보이는 사진. 실제 치수(cm, 리터)를 적은 자료. 쇼와 시절 흔한 플라스틱 물뿌리개 사진(Commons 「Watercan.png」 주황 플라스틱 것은 배경을 검게 오려 낸 586 x 329 px 작은 이미지라 쓰지 않았다)
