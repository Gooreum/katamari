- 잰 것: 윗면 원의 왼쪽 끝 x=210, 오른쪽 끝 x=1105 → 지름 895 px. 타원 뒤쪽 위 y=765, 앞쪽 아래 y=1300 → 세로 535 px, 535/895 = 0.60 이라 약 37° 위에서 내려다본 각이다. 앞 테두리 y=1300 → 밑동 y=1585, 옆면 높이 285 px → 높이 / 지름 = 0.32. 가운데 사각 물구멍은 x=415→880 (465 px, 지름의 0.52), 앞뒤 y=885→1160 (275 px). 대나무 꼭지 주둥이는 (700~790, 830~890) 에 있고 통 지름 약 85 px (지름의 0.095), 수평에서 약 30° 로 내려온다
- 살릴 것: 지름 : 높이 = 1 : 0.32 인 납작한 원기둥 한 덩어리 — 받침도 굽도 없이 통짜 그대로 땅에 놓인다 · 윗면 한가운데를 지름의 0.52 짜리 정사각형으로 파낸 물구멍, 물은 구멍 위 테두리 바로 아래까지 차 있다 · 구멍을 사방으로 두른 네 글자(오른쪽 隹, 앞쪽 疋)가 윗면을 옛 동전처럼 만든다 · 통 지름이 원의 0.1 인 대나무 꼭지가 뒤 오른쪽 위에서 수평 30° 로 내려와 구멍 안으로 물을 떨군다
- 버릴 것: 나무 국자와 걸침대, 둘레의 젖은 검은 자갈, 대나무 지지대와 검은 묶음끈, 뒤쪽 덤불·고사리·삼나무 가지
- 본 것: 마른 윗면은 분홍기 도는 화강암 (151,141,139), 비에 젖은 오른쪽 윗면은 (108,89,66) 으로 훨씬 어둡고 누렇다. 그늘진 옆면 (75,69,65), 구멍 속 물은 (23,23,18)~(60,53,43) 로 거의 검다. 새김 글자는 둘레보다 밝은 (198,178,180). 대나무는 (145,163,121)~(116,126,74) 초록이고 잘린 주둥이 단면만 (110,83,66) 살구색. 화강암 알갱이가 굵게 드러나고 옆면은 아래로 갈수록 물때로 검어진다
- 못 찾은 것: 이 사진은 료안지의 이름난 銭形 つくばい라 吾唯足知 네 글자가 새겨져 있는데, 1970~80년대 일본 여염집 마당에 흔했던 민무늬 물확 사진은 못 찾았다. 밑동이 어둠에 묻혀 땅에 닿는 선을 ±20 px 안으로밖에 못 짚었고, 눈높이 정면 사진이 없어 지름 대비 높이가 실제보다 커 보일 수 있다. kew.jpg 는 영국에 만든 복제품이라 시대·산지 고증으로는 쓸 수 없다
