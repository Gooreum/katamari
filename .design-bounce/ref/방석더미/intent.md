- 잰 것: (main.jpg) 더미 윗면 뒤 가장자리 y≈408 → 다다미에 닿는 아래 y≈850. 앞면 폭은 층마다 355~395 px (y=700 에서 x=215 → 600 약 385 px). 앞면 높이(윗 방석 앞 가장자리 y≈470 → 850) 약 380 px — 높이 : 폭 ≈ 1 : 1. 가운데 세로줄(x=400~480) 색 띠를 위에서부터 세면 남색 → 남색·흰 줄무늬 → 탁한 장밋빛 → 파랑(얇게) → 겨자색 → 장밋빛 → 빨강·초록 줄무늬 → 회백색 얼룩 → 장밋빛 → 겨자색 → 회청색 가스리 → 짙은 색 → 장밋빛 → 겨자·흰색, 약 14 장(가려진 것이 있어 13~15). 한 장 두께 약 25~30 px = 앞면 폭의 0.07
- 잰 것: (main.jpg) 층마다 왼쪽 끝이 x=205~267 사이에서, 오른쪽 끝이 x=555~610 사이에서 들쭉날쭉하다 — 좌우 어긋남 폭이 앞면 폭의 최대 0.15. 위쪽 네 장(y<560)은 오른쪽으로, 가운데·아래(y=690, 760)의 장밋빛 방석은 왼쪽으로 삐져나온다. 맨 위 남색 방석은 윗면이 보이고 폭(x=267 → 590, y=450) 323 px 로 아래 장들보다 좁다
- 잰 것: (side.jpg) 같은 무늬 방석 앞면 x≈595 → 885 (290 px), y≈700 → 945 (245 px). 가운데 세로줄 밝기에서 방석 사이 어두운 골이 25~30 px 간격으로 잡혀 8~9 장, 한 장 두께 = 앞면 폭의 0.09~0.10. 왼쪽 옆면(x≈500 → 595)이 어둡게 보인다. 앞 두 모서리에 금색 술이 층마다 매달린다(오른쪽 y≈715~760, 790~830, 왼쪽 y≈800~830, 870~930)
