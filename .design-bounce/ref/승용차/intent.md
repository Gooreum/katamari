# 승용차 (1980년대 일본 소형 세단 — 토요타 카롤라 E70/KE70)

- 출처: https://commons.wikimedia.org/wiki/File:Toyota_Corolla_DX_(profile),_Denpasar.jpg (2026-09-16 내려받음, `main.jpg` / 1920×790 px, 원본 3562×1466 px, CC BY-SA 4.0, 촬영자 Sabung.hamster)
  - 발리 덴파사르 노변에 세워둔 카롤라 DX 4도어 세단을 **차체 왼쪽에서 거의 정확한 정측면**으로 찍은 사진입니다. 차가 화면을 가로로 꽉 채우고 앞뒤 범퍼 끝이 모두 프레임 안에 들어옵니다. 카메라가 차 중앙보다 약간 앞쪽에 있어서 앞바퀴가 뒷바퀴보다 조금 크게 찍혔습니다.
  - 보조 사진 `alt.jpg`: https://commons.wikimedia.org/wiki/File:Toyota_Corolla_E70_4_door_sedan.jpg (1338×803 px, CC BY-SA 3.0, 촬영자 Charles01, 1980년 촬영). 같은 E70 세단을 앞쪽 45도에서 찍은 그 시절 사진입니다. 앞얼굴(사각 헤드램프와 가로살 그릴), 지붕에서 트렁크로 넘어가는 선, 그리고 시절에 맞는 강철 휠을 볼 때 씁니다.

- 잰 것 (`main.jpg` 1920×790 px 위에서 픽셀로 잰 값. 괄호 안은 전장을 1로 둔 비율)
  - 전장: x=95(뒤 범퍼 끝) ~ x=1832(앞 범퍼 끝) = **1737 px** (1.000)
  - 전고: y=103(지붕 윗선) ~ y=695(타이어 접지선) = **592 px** (0.341)
  - 휠베이스: 뒷바퀴 허브 x≈490 ~ 앞바퀴 허브 x≈1567 = **1077 px** (0.620)
  - 바퀴(타이어 바깥) 지름: 앞바퀴 y=452~692 = **240 px** (0.138). 가로로도 x=1450~1690 = 240 px 으로 같습니다.
  - 앞 오버행(앞 허브에서 앞 범퍼까지): **265 px** (0.153) / 뒤 오버행(뒤 허브에서 뒤 범퍼까지): **395 px** (0.227). 뒤가 앞보다 1.5배 깁니다.
  - 전고를 세로로 쪼개면 — 유리대(지붕선 y=110 ~ 벨트라인 y=292) **182 px**(전고의 0.31), 옆판(벨트라인 ~ 로커 아랫선 y=590) **298 px**(0.50), 로커 아래 바닥까지 **105 px**(0.18).
  - 지붕이 평평한 구간: x=600~1150 = **550 px**, 전장의 0.32. 이 평평한 구간이 휠베이스 한가운데보다 약간 뒤에 놓입니다.
  - 정리하면 — **전장 : 전고 = 2.93 : 1**, **휠베이스 : 바퀴지름 = 4.5 : 1**, **전고 : 바퀴지름 = 2.47 : 1**
  - 카메라 위치 때문에 휠베이스 비율이 실제보다 조금 크게(0.620) 나옵니다. 앞바퀴가 카메라에 더 가깝기 때문입니다.

- 살릴 것
  1. 완전히 각진 3박스 실루엣. 보닛·객실·트렁크가 각각 평평한 수평면으로 끊깁니다. 둥글린 곳이 거의 없습니다.
  2. 얇고 곧은 기둥과 큰 유리면. 앞뒤 기둥이 거의 직선이고 유리대가 전고의 3분의 1을 차지합니다.
  3. 옆면을 앞뒤로 가로지르는 얕은 프레스 라인 두 줄(벨트라인 아래 한 줄, 문 손잡이 높이 한 줄)과 로커 위의 낮은 몰딩.
  4. 바퀴가 작고 펜더 아치도 작습니다. 타이어 윗면과 펜더 아치 사이 틈이 거의 없어 바퀴가 몸통에 꽉 끼어 보입니다.
  5. 앞뒤로 튀어나온 검은 고무 범퍼. 차체 색과 분리된 어두운 띠로 앞뒤 끝을 마감합니다.

- 버릴 것
  - 번호판과 그 안의 글자·숫자, 'TOYOTA' 각인, 문 손잡이 열쇠구멍, 주유구 뚜껑의 나사 자국.
  - 배경 전부. 회색 돌담, 꽃, 연석, 아스팔트, 차 아래 그림자, 바닥의 잡초.
  - 사이드미러·와이퍼·안테나처럼 3m 크기에서 한 픽셀도 안 되는 가는 부속.
  - 휠의 5스포크 알로이 무늬. 이 차는 나중에 바꿔 끼운 휠이라 시절에 맞지 않습니다. `alt.jpg` 의 강철 휠(작은 구멍 네 개와 가운데 캡)이 시절에 맞습니다.

- 본 것 (`main.jpg` 에서 구역 평균으로 읽은 RGB)
  - 지붕 윗면 (180,183,183), 햇빛 받는 앞문 옆판 (188,189,193), 그늘진 뒷펜더 (143,144,147). 차 몸통은 채도가 거의 없는 은색이고 밝은 면과 그늘진 면의 차이가 45 정도밖에 안 납니다. 도장이 낡아 광이 죽었고 반사가 넓고 부드럽습니다. 옆판 한가운데에 가로로 길게 흰 하이라이트 한 줄만 남습니다.
  - 유리 (149,162,165). 살짝 청록으로 기울고 몸통보다 어둡습니다. 안이 비치지 않고 한 덩어리 면으로 읽힙니다.
  - 타이어 (56,54,55), 범퍼 검정 (43,44,44). 범퍼가 타이어보다 더 어둡습니다.
  - 휠 알루미늄 (161,156,148). 몸통 은색보다 조금 어둡고 따뜻합니다.

- 못 찾은 것
  - **일본에서 찍힌** E70 카롤라의 정측면 사진을 못 구했습니다. 위키미디어 공용의 E70 세단 분류 150여 장을 전부 훑었는데 정측면으로 찍힌 것은 이 발리 개체 한 장뿐이고 나머지는 전부 45도 각도입니다. 남은 것은 오스트레일리아·태국·방글라데시·싱가포르 개체였습니다.
  - 닛산 서니(B310)와 혼다 시빅 1세대의 자유 라이선스 정측면도 못 찾았습니다. 위키미디어 공용에서 해당 분류를 찾았으나 분류가 비어 있거나 응답이 없었습니다.
  - 1970~80년대 당시에 찍힌 정측면 사진은 없었습니다. `main.jpg` 는 2014년에 찍힌 같은 세대 차입니다. 시절 감(색·휠·번호판)은 1980년에 찍힌 `alt.jpg` 를 대신 봅니다.
  - 카탈로그 제원(밀리미터 단위 전장·휠베이스)과 대조하지 못했습니다. 위의 수치는 전부 사진에서 잰 픽셀 값과 그 비율입니다.
